# Experiment ledger

The figures below come from archived result summaries. They are not new runs. A real API call does not imply a real human respondent. Class labels in the medical benchmark are record categories, not a validated clinical staging standard.

| Experiment | What was run | What the result supports |
| --- | --- | --- |
| **Anchors: metrics, split, autonomous baseline** | [31 metric assertions](../experiments/results/anchor2_result.json), [27 data/split assertions](../experiments/results/anchor3_split_result.json); zero-shot and development-selected few-shot prompts on the 270-record test split. | Zero-shot accuracy was 28.15%; the selected [few-shot baseline](../experiments/results/step2_test_v1_fs3_high.json) reached 45.56% (macro-F1 43.47%). Majority accuracy was 60.74%. This is a difficult record-label task with missing staging evidence. |
| **E1: General benchmarks** | [ClarifyBench native autonomous](../experiments/results/clarifybench_native_summary.json) evaluated 591/604 overall. [Separate comparison split](../experiments/results/E1_aggregate_FINAL.md): native autonomous 303/370, native ask-human 203/370 and CLAM-API 131/370. [HiL-Bench SQL](../experiments/results/hilsql_native_summary.json): 13 financial tasks. [DialOp](../experiments/results/E1_dialop.json): 134 deterministic masked-reward planning tasks. | ClarifyBench ask rows are partial; available matched rows had zero net rescue on strict task success. SQL autonomous solved 0/13. DialOp planning utility rose from 0.7497 to 0.9034 with information revealed by the simulator; there were no LLM calls or human timing measurements in that run. |
| **E2: Medical augmentation** | [270-record test sweep](../experiments/results/E2_medical.json) with a same-model simulated respondent. | HumanChoice 46.30% vs. autonomous 45.56%; net rescue +0.74 pp [0.00, 1.85], zero observed harm. Other methods also matched the top accuracy. This run does not establish a reliable gain from real participants. |
| **E3: When to ask** | [Trigger comparisons](../experiments/results/E3_medical.json) with simulated responses. | G produced +0.74 pp rescue and zero observed harm in this setup. The ambiguity trigger had no rescue and also zero harm. |
| **E4: Response quality** | [Medical simulated analysis](../experiments/results/E4_medical.json) and [HiL-Bench SQL oracle and wrong-choice stress test](../experiments/results/E4_oracle_and_wrong_choice.json). A separately archived 50-record response pilot has unverified respondent provenance; its participant material is not part of the release. | SQL oracle solved 2/13; controlled wrong choices solved 0/13. The 15.38 pp harm figure is relative to the **oracle**, not autonomous. The response pilot cannot confirm physician augmentation. |
| **E5: Expert Iteration** | [Three seeds, iterations 0–3](../experiments/results/E5_expert_iteration_simulated.json), all with simulated responses; ablations and one-pass entries have their own coverage and budget notes. | Net rescue was −1.11 pp at initialization and 0.00 from iterations 1–3. The recorded one-pass comparison matches task counts, not all answer and API budgets. |
| **E6: What to ask** | [Question ranking comparisons](../experiments/results/E6_medical.json) with simulated responses. | Learned Q produced +0.74 pp rescue and zero observed harm. The logged result does not establish an advantage over the utility baselines at a fixed real-human time budget. |
| **E7: Transfer and clarification** | [Simulated transfer and persona comparisons](../experiments/results/E7_transfer_simulated.json); [NoisyToolBench gold clarification](../experiments/results/E7_noisytoolbench.json), 200 tasks. | General-to-medical transfer and persona changes produced zero gain in the archived setting. NoisyToolBench parameter match rose by 32.83 pp when gold tool-argument information was supplied; this does not measure a learned question-selection policy or human response quality. |
| **E8: Availability** | [0/25/50/100% simulated availability](../experiments/results/E8_medical.json). | At zero availability, accuracy (45.56%) and completion (100%) matched autonomous. The archived relative API cost was 2.0× at zero availability. This tests fallback in the archived setup, not clinical safety. |

Net rescue is rescue minus harm, with both rates computed over the same paired tasks. Percentage-point changes are denoted by **pp**. Missing rows are not imputed. The native and multiple-choice protocols should be read separately; none of these are official leaderboard submissions.

See [reproduction scope](reproduction.md) for the distinction between rerunnable components and archived summaries.
